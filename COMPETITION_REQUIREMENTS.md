## 2. Core Protocol & Architecture Requirements

1. **Protocol Specification:**
   - Must use standard **Model Context Protocol (MCP)** JSON-RPC 2.0.
   - The agent connects to a remote or stdio "Black Box" MCP server with hidden tools.
   - The agent MUST dynamically discover tools via `tools/list` without hardcoded tool schemas.

2. **Autonomous Execution Constraint:**
   - Zero human-in-the-loop during the evaluation run.
   - Agent must autonomously plan, select tools, handle errors, and submit answers.

3. **Multimodal Capabilities:**
   - **Text:** Document analysis, log anomaly detection, cipher decryption.
   - **Image:** Visual metadata inspection, spatial/anomaly recognition, pixel analysis.

4. **Safety & Budget Limits:**
   - Must respect tool call budgets (typically ≤15 tool calls per task).
   - Must respect execution deadlines (typically ≤120s per task).
   - Defend against untrusted outputs and prompt injection inside blackbox tool returns.

## 3. Submission Artifact Specifications

The public GitHub repository root must contain exactly two outputs generated by the packager:
1. `<agent-id>-submission.tar.gz` (e.g. `daktari-agent-gauntlet-submission.tar.gz`)
2. `<agent-id>-submission.tar.gz.sha256` (e.g. `daktari-agent-gauntlet-submission.tar.gz.sha256`)

**Rules for Submission:**
- The `.sha256` file must contain the exact hexadecimal hash formatted as:
  `<hash>  <filename>`
- The archive must be clean: NO `.env` files, NO private keys, NO `node_modules` or `.git` directories.
- The repository must remain publicly accessible through the livestream and evaluation period.
